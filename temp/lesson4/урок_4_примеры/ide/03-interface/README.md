# Неявная реализация интерфейса

**Алгоритм:** `Notify` получает отправителя через `Notifier` и вызывает `Send`; в `main` передаются `Email` и `Push`.

**Синтаксис:** интерфейс `Notifier` перечисляет сигнатуры методов. Тип удовлетворяет интерфейсу неявно, если реализует все его методы; ключевого слова `implements` нет. Поэтому важны оба метода (`Send` и `GetAddress`), даже если `Notify` вызывает только первый. Строки `var _ Notifier = Email{}` и `var _ Notifier = Push{}` — compile-time проверки соответствия.

`SMS` тоже реализует `Notifier`, хотя в программе не используется. Получатель-значение `func (e Email)` подходит для значений `Email`.
