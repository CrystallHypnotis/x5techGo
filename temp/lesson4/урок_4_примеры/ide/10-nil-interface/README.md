# Nil-интерфейс и типизированный nil

**Алгоритм:** сначала `n` — nil-интерфейс. Затем в него помещается nil-указатель `p` типа `*Email`; теперь интерфейс не nil, и вызванный метод сам проверяет получателя.

**Модель:** интерфейсное значение концептуально хранит пару `(динамический тип, динамическое значение)`. У `var n Notifier` нет ни типа, ни значения, поэтому `n == nil`. После `n = p` пара равна `(*Email, nil)`: указатель nil, но интерфейс — нет. `%T` показывает динамический тип. Метод с получателем `*Email` может получить nil; проверка `if e == nil` не даёт обратиться к полю.

**Практический вывод:** типизированный nil, упакованный в интерфейс, не является nil-интерфейсом. Если нужно вернуть отсутствие значения, возвращайте сам `nil` интерфейс.
