# Type switch

**Алгоритм:** `Describe` определяет конкретный тип значения и строит описание. `main` перебирает значения разных типов, включая указатель, `nil`, число и строку.

**Синтаксис:** `any` — псевдоним пустого интерфейса, способного хранить значение любого типа. `switch v := value.(type)` — специальный type switch; внутри каждой ветки `v` имеет тип соответствующего `case`. `case nil` обрабатывает nil-интерфейс, `default` — остальные типы.

Проверка `v == nil` в ветке `case *Email` отдельная: интерфейс может содержать типизированный nil-указатель. Такой интерфейс не равен `nil`.
