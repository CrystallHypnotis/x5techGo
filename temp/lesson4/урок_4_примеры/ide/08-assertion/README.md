# Утверждение типа

**Алгоритм:** цикл берёт каждое значение `Notifier` и проверяет, является ли его динамическое значение `*Email`. Затем проверяется соответствие анонимному интерфейсу с методом `Send`.

**Синтаксис:** `e, ok := n.(*Email)` — безопасное утверждение типа: при совпадении `ok` равно `true`, иначе `false` (а `e` будет nil). Одно-result форма `e := n.(*Email)` при несовпадении вызвала бы panic. Анонимный `interface { Send(string) }` задаёт интерфейс прямо в выражении. Последняя проверка успешна, потому что `Notifier` имеет тот же метод.

`%T` выводит динамический тип; `%q` форматирует строку в кавычках.
