# Набор методов и указатель-получатель

**Алгоритм:** метод `Counter.Send` увеличивает счётчик. Сначала он вызывается через переменную `c`, потом через интерфейс, содержащий `&c`.

**Синтаксис и правило:** `func (c *Counter) Send(...)` имеет получатель-указатель. Набор методов `*Counter` содержит методы с получателями `*Counter` и `Counter`; набор `Counter` — только методы с получателем `Counter`. Поэтому `*Counter` реализует `Notifier`, а `Counter` — нет. Проверка `var _ Notifier = (*Counter)(nil)` выполняется компилятором.

Прямой вызов `c.Send(...)` разрешён: компилятор может взять адрес адресуемой переменной. Это не означает, что значение `Counter` можно присвоить интерфейсу. Строка `var bad Notifier = c` намеренно вызывает ошибку — закомментируйте её для запуска. Счётчик после двух вызовов равен `2`.
