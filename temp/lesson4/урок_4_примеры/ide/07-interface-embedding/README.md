# Встраивание интерфейсов

**Алгоритм:** `Show` печатает имя отправителя и отправляет ему сообщение. `Console` предоставляет оба требуемых метода, поэтому его можно передать в функцию.

**Синтаксис:** `NamedSender` включает интерфейсы `Sender` и `Named`. Набор методов объединённого интерфейса состоит из методов обоих: `Send(string)` и `Name() string`. Типы реализуют интерфейсы неявно — достаточно иметь нужные методы.
