# Динамическая диспетчеризация

**Алгоритм:** `Dispatch` проходит по срезу отправителей и вызывает каждого. При первой ошибке возвращает её сразу; если всё успешно — возвращает `nil`.

**Синтаксис:** `[]Notifier` — срез интерфейсных значений, поэтому в нём лежат `Email`, `Push`, `Console`, реализующие `Send(string) error`. `for _, n := range all` перебирает элементы, отбрасывая индекс через `_`. В `if err := n.Send(message); err != nil` переменная `err` объявляется только для этого условия.

Все отправители печатают сообщение, затем `fmt.Println` отображает `ошибка: <nil>`.
