# Встраивание структуры

**Алгоритм:** `Email` содержит встроенный `Base`. Метод `Log` доступен через `e.Log`; собственный `Email.Name` затеняет продвинутый `Base.Name`. В `e.Report()` вызывается метод `Base`, у которого получатель остаётся типа `Base`.

**Синтаксис:** поле `Base` без явного имени — embedding (встраивание), а не наследование. Его методы продвигаются к внешнему типу, если нет конфликта имён. `e.Base.Log(...)` явно обращается к встроенному полю.

Поэтому `e.Name()` вернёт `email`, но `e.Report()` напечатает `Report: base`: `b.Name()` вызывается на получателе `Base`, не на `Email`. Встраивание также не позволяет присвоить `Email` переменной типа `Base`.
