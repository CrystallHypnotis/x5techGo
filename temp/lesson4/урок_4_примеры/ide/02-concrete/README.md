# Конкретные типы

**Алгоритм:** `NotifyEmail` принимает `Email` и вызывает его `Send`. В `main` сначала передаётся `Email`, затем — `Push`.

**Синтаксис:** `n Email` означает, что параметр должен быть именно типа `Email`. Совпадение методов у `Email` и `Push` не делает эти структуры взаимозаменяемыми. Go не использует наследование типов по совпадающим методам.

**Важно:** пример намеренно не компилируется из-за `NotifyEmail(Push{}, ...)`. Интерфейс в следующем примере позволит принимать разные типы с нужными методами.
