# Методы и получатель-копия

**Алгоритм:** создаётся `Email`, печатается его адрес методом `Label`, вызывается `Rename`, затем адрес печатается снова. `Rename` имеет получатель-значение и меняет копию структуры, поэтому исходный адрес не изменится.

**Синтаксис:** `func (e Email) Label() string` объявляет метод типа `Email`; `(e Email)` — получатель. `Email{Address: ...}` — составной литерал с именованным полем. Чтобы изменить исходную структуру, используйте указатель-получатель: `func (e *Email) Rename(...)`.

**Ожидаемо:** два раза выводится `old@example.com`.
