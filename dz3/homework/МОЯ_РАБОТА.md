## Что делает программа

Программа демонстрирует отправку уведомлений через email и push каналы, которые реализуют общий интерфейс Notifier. Показаны случаи: успешной рассылки, обработки пустого сообщения, отсутствующей настройки (не указан Device Id) и продолжение рассылки, если один из каналов вызывал панику

## Как запустить

Из папки `dz3`:

```bash
gofmt -w practice/tasks.go cmd/notify/main.go
go test -v ./practice -run TestHomework
go test ./...
go build ./...
go vet ./...
go run ./cmd/notify
gofmt -l practice/tasks.go cmd/notify/main.go
```

## Проверенные случаи

1) Успех: Dispatch возвращает nil, в истории email и push появляется сообщение
2) Пустой текст: Dispatch возвращает ошибку, распознаваётся через errors.Is, истории каналов не меняются
3) Нет настройки: push без DeviceID возвращает *SendError, ошибка распознаваётся через errors.As
4) Сломанная реализация: SafeDispatch преобразует панику в ошибку ErrNotifierPanic и продолжает рассылку

## Обработка ошибок

Dispatch отправляет сообщение по каналам по порядку, при ошибке вернёт её и закончит рассылку 
SafeDispatch отправляет сообщение по каналам с помощью SafeSend, полученные ошибка сохраняет в слайс и продолжает работу. В конце вернёт слайс ошибок

errors.Is проверяет, что полученная ошибка соответствует указанной (в задании сравнивает с practice.ErrEmptyMessage)
errors.As проверяет, что полученная ошибка соответствует указанной обёрнутой ошибке(в задании *practice.SendError)
recover находится в SafeSend, вокруг отдельного вызова Send, так паника превращается в ошибку для одного канала, не останавливая обработку остальных
