Сервис заказов на Go. Данные хранятся в памяти, реализованы операции добавления, обновления, поиска зазказов,
а так же вывод содержимого хранилища


Запуск: go run ./cmd/api, 
Адрес бэкенда http://localhost:8080
Свагер: http://localhost:8080/swagger/index.html

API: 
| Метод | Путь | Назначение | Успешный код |
|---|---|---|---:|
| GET | `/health` | Проверка доступности сервиса | 200 |
| POST | `/api/v1/orders` | Создание заказа | 201 |
| GET | `/api/v1/orders` | Получение списка заказов | 200 |
| GET | `/api/v1/orders/{id}` | Получение заказа | 200 |
| PATCH | `/api/v1/orders/{id}/status` | Изменение статуса | 200 |
| GET | `/api/v1/orders/{id}/history` | Получение истории статусов | 200 |
